*NeoAI-utils.txt*  Utility Modules Reference

==============================================================================
Utility Modules Overview                                *NeoAI-utils-overview*

The utils directory provides shared utility functions used across all modules.

==============================================================================
Module List                                             *NeoAI-utils-modules*

utils/init.lua:
  Entry point, exports all utility modules

utils/async.lua:
  Async primitives (Promise/Deferred/AbortSignal)
  - Deferred.new(): Manual resolve/reject promise
  - new(executor): Promise with executor(resolve, reject)
  - all(promises): Await all promises
  - race(promises): First settled wins
  - retry(fn, opts): Retry with exponential backoff
  - sleep(ms): Delay
  - create_signal(): AbortSignal (abort/reason/subscribe)
  - Signal:abort(reason), :aborted(), :subscribe(cb)

utils/json.lua:
  JSON utilities
  - encode(value): Encode Lua value to JSON string
  - decode(json_str): Decode JSON string to Lua value
  - decode_or_nil(json_str): Safe decode (returns nil on error)
  - decode_line(line): JSONL single line decode

utils/http.lua:
  Async HTTP client (curl via jobstart)
  - request(opts): Non-blocking request
    opts: { base_url, path, method, headers, body, query, timeout_ms, stream }
  - stream support: on_chunk(data, done) callback for SSE
  - AbortSignal: kills curl job on abort
  - get_json(base_url, path, opts): GET JSON convenience

utils/fs.lua:
  File utilities
  - read_file/write_file/append_file/delete_file
  - ensure_dir/mkdir
  - read_jsonl/append_jsonl/repair_jsonl (torn line recovery)
  - exists/is_dir/list_dir/join/basename/dirname

utils/stringx.lua:
  String utilities
  - trim/split/startswith/endswith
  - template ({} placeholders)
  - glob_to_pattern/glob_match
  - truncate/capitalize/uuid/is_blank

==============================================================================
Logger Configuration (kernel/logger.lua)              *NeoAI-logger-config*

The logger lives in kernel/logger.lua (moved from utils to satisfy the
kernel → utils dependency rule).

>
    log = {
        level = "WARN",           -- DEBUG, INFO, WARN, ERROR, FATAL
        path = vim.fn.stdpath("cache") .. "/NeoAI/neoai.log",
        format = "[{time}] [{level}] {message}",
        max_size = 10485760,      -- 10MB
        max_backups = 5,
        print_debug = false,
    }
<
